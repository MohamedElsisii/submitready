# Contributing to SubmitReady

Thank you for helping researchers submit with less pain.

## Add a journal profile

A journal profile tells SubmitReady where a journal's guidelines live and which reference style it uses. It does not store the guidelines themselves; SubmitReady reads them live on every run.

1. Copy `journals/_TEMPLATE.yaml` to `journals/<journal-slug>.yaml`.
2. Fill every field you can verify. Each value needs its source URL and the date you checked it.
3. Open a pull request, or open an "Add my journal" issue if you prefer.

## Report a bug

Open a "Bug report" issue. Never attach an unpublished manuscript; describe the problem or share a small made-up example instead.

## Ground rules

- No real manuscripts, reference libraries or patient data in the repo.
- No journal facts without a source.
